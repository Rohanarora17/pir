# ADR-NNN: Decision title

- Status: `proposed`
- Date: `YYYY-MM-DD`
- Deciders: name the people responsible for accepting the decision
- Linked research questions: list each `RQ-NNN`
- Linked experiments: list each `EXP-NNN`, or explain why executable evidence is unnecessary

## Context

State the engineering question, the affected interface or guarantee and the constraints that make a
decision necessary. Separate confirmed facts from hypotheses.

## Evidence

Link repository-relative source records, experiment directories and raw results. State which decision
criterion each item satisfies. Identify upstream performance claims as source findings. Do not report
them as local measurements unless the linked experiment reproduced them.

## Decision

State the selected option and the boundary of the decision. Include exact versions, parameters and
formats when they affect compatibility or security.

## Consequences

Record the expected benefits, costs, limitations and implementation work introduced by the decision.

## Rejected alternatives

For every credible alternative, state the evidence or constraint that caused it to be rejected. Do
not reject an unmeasured option on performance grounds.

## Revisit condition

State the new evidence, upstream change or measured limit that would justify opening a replacement
ADR.
